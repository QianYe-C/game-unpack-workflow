# 工具目录

更新日期：2026-10-17。以实际随附文件为准。新项目先读 [统一入口](../新游戏迁移还原入口.md)。项目专属/历史临时脚本不作为通用入口，未导入 cocosgame2 的构建缓存和分析产物。

## 调用与依赖

- 在本工具流根目录执行；路径显式指定为当前项目，不沿用脚本中的旧项目默认值。
- Python工具先读 `--help`；图片链路通常需 Pillow，Unity资源链路需 UnityPy；具体依赖按脚本import核对。预抓、自检及Web data封装使用Python标准库。
- 微信解包需要 Node.js；Web→TT转换还会调用Node读取settings；Il2CppDumper源码需匹配的.NET SDK与其依赖。本目录不承诺这些运行环境已经安装。
- 覆盖回写前做dry-run（若支持）及备份；`u3d_run_pipeline.py` 是若干Unity资源处理阶段的封装，含项目结构假设，不是任意游戏的一键还原器。

## Cocos和微信

| 工具 | 实际用途/边界 |
|---|---|
| `cocos_prefetch_assets.py` | 从本地 `assets/*/config.*.json` 枚举2.x资源，支持默认远端、单Bundle远端、pack过滤、并发与JSON报告；不自动镜像壳/config或发现全部动态地址 |
| `cocos_export_source_images.py` | 整张纹理解码、导出manifest；不是完整场景/图集/Prefab还原 |
| `cocos_import_source_images.py` | 按manifest增量整纹理回写，尺寸保持，支持dry-run与备份 |
| `cocos_image_utils.py` | 图片公共库；已知加密格式带固定标记/密钥，不是任意加密的解密器 |
| `convert_cc24_web_to_tt.py` | Cocos2.4 Web→TT骨架；随附模板引擎2.4.15，保留模板引擎，需核对源版本、方向、AppID及平台SDK |
| `wxapkg_batch_unpack.js` / `.cmd` | 离线批量解密/解包与报告；不自动完成小游戏模块到Web的全部重建 |

```powershell
python .\tools\cocos_prefetch_assets.py --project .\myprojects\GAME\webprojects --scan-only --report .\myprojects\GAME\logs\scan.json
python .\tools\cocos_prefetch_assets.py --project .\myprojects\GAME\webprojects --base-url "https://YOUR_HOST/GAME" --bundle-url "main=https://YOUR_CDN/main" --report .\myprojects\GAME\logs\prefetch.json
python .\tools\convert_cc24_web_to_tt.py --source .\myprojects\GAME\webprojects --template .\templates\bytedance-mini-game-cc2.4 --dest .\myprojects\GAME\output\tt
```

`--bundle-url`的URL是该Bundle远程根，不再额外拼 `assets/<bundle>`。没有默认 `--base-url` 时，全部所选Bundle都须映射。实际URL按原版请求确认；上例占位域名不可直接使用。

### 预抓退出码和报告

| 码 | status | 判据 |
|---|---|---|
| 0 | ok | 有有效config、有资源条目，最终文件复查完整 |
| 1 | incomplete | 最终仍缺资源，或远程/线程/下载失败 |
| 2 | error | 缺项目/assets/config、零条目、错Bundle、坏配置或地址未覆盖 |

保留旧报告字段，`missing_local`/`existing_local`现在表示最终复查结果；新增`initial_missing_local`、`initial_existing_local`记录下载前状态，另有`config_count`、`config_files`、`status`和`exit_code`。`--scan-only`存在缺失也返回1。旧脚本若只看退出码或下载前计数，应按新语义更新。

去除了`.bak_before_cap32`候选；目录或备份文件不能冒充资源。扫描通过不证明清单外动态资源、格式解码、平台接入和实际游戏行为通过。

## 库完整性自检

```powershell
python .\tools\workflow_selfcheck.py --report .\logs\workflow-selfcheck.json
```

标准库、只读、无需联网；检查入口、相对文档链接、来源清单/正文哈希与TT模板依赖。0表示库检查通过，1表示实际缺件/损坏/失效链接。登记的31份历史缺文只作警告。它不执行游戏，也不替代项目资源扫描、SDK、引擎版本和目标设备验收。
