## 统一证据口径

- 静态观察：给出源包摘要、文件/对象/方法、实际调用和消费位置；字段名只是搜索线索。
- 原版动态观察：给出版本、设备、输入/进度/时钟/种子、取样步骤、状态恢复和原始输出。替身或受控改值须列出边界。
- 迁移实现：给出目标资源/脚本、身份映射及实施差异，避免把健壮性改动称为完全等价。
- 目标验证：原版样本与目标结果分别生成；小样、全量配置、真实交互、构建、真机逐层报告。
- 未知与缺失：区分缺文件、不可读、未采样、未实现、近似实现和已验证。标题或索引不能代替正文。
