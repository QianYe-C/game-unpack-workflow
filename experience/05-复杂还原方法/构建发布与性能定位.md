# 构建、发布与性能定位

整理日期：2026-10-17。适用于“预览正常但目标失败”、远程包未就绪、包体超限、帧率下降和 Draw Call 优化。

## 从同一输入验证实际产物

保存源文件摘要、编辑器/引擎/平台工具版本、参数和构建日志，验证 Web 与目标平台各自产物；源码类型检查、编辑器工具成功和 Web 预览只证明对应一层。

开发环境正常、生产包 loading 不动时，检查动态 import 是否循环依赖入口，尤其入口顶层 await 等待异步渲染初始化；目标 compiler 的 Map/Set 展开、解构、Babel helper 和迭代器要从实际输出验证。只针对已确认类型与产物问题修复，不批量替换所有数组展开。

原始构建保留不动，候选在独立目录生成；修复后重新构建，不能补丁改旧产物再当作新的源构建。编辑器保存超时或 import 对话框未解决时，检查实际文件与重新打开结果，不沿用工具返回值。

## 资源补齐门禁

先镜像入口和全部已知 Bundle config，再扫描 import/native。没有 config、错 bundle、零条目或缺地址都应返回错误；下载后重新扫描，配置数量、资源数和缺项要一起看。清单以外的动态路径、运行时解密和平台SDK不由扫描结果证明。

依次覆盖冷启动、首次进后续关、跨包场景切换、重复进入、失败后重试、销毁后迟到加载、缓存命中与清空缓存。不把 404、服务未启动、HTTP/HTTPS/域名校验和脚本错误混作同一资源问题。

## 包体、分包与远程交付

1. 本地代码、首屏依赖、远程素材、可选模式和运行缓存分别列账。先看真实引用图再拆包。
2. 引擎/平台的 Bundle root 和 UUID 不是任意可互换参数；MD5 模式清单、版本、入口与原路径须一起发布。
3. PNG/WebP/ASTC/ETC 等能力分引擎、目标平台、实际设备验证。保留源图，不因浏览器能解码就批量转成目标不支持的格式。
4. 索引PNG检查字形/透明alpha/颜色域；压缩字节、解码像素、GPU格式和内存是不同指标。
5. 候选代码包和远程包逐文件记录摘要；HTTPS、域名、缓存失效、失败重试、弱网与真机另做验证。HTTP 请求能取字节不代表引擎实际加载成功。
6. 用快照构建时恢复配置与异常清理属于流程；发布成功也需要远端可用和目标运行证据。旧包和回滚映射保留到新候选验证结束。

清理前审计序列化 UUID、压缩 UUID、动态路径和工具依赖；通过编辑器资源管理能力处理作者化资产，保留 meta 与可恢复备份。分别报告源工程、压缩包、分包和运行内存，不把一个口径的节省外推到另一个。

## 性能先测时间，再查批次

固定设备、分辨率、进度、对象数、帧率设置和操作，分别采样冷启动/首次 shader 编译与稳定运行。至少记录帧间隔与P95、CPU热点、渲染提交、GPU时间（可获取时）、DC、CPU/GPU内存口径和加载耗时。

DC 下降却更慢时，优先查新加的逐帧场景遍历、频繁排序、上传/复制、JSON解析、缓存失效和物理查询。把动态数据全缓存也可能错误；固定节点引用缓存须处理销毁、场景替换和新实例。物理采样/诊断不能留在生产热路径。

同材质同纹理仍拆批时，观察实际 renderData chunk/bufferId、混合/深度状态、遮罩、材质实例和全局排序。宏或缓冲容量可能要在反序列化前设置；保留索引位宽余量，不照抄某项目的 KB 常量。

小游戏与 Web 的动态合图默认值可能不同，应读产物与运行时；保留原图缓存会增加内存。多纹理UI、粒子绘制槽或自定义renderer还必须验证遮罩、图层、alpha和生命周期，不能为DC破坏原视觉。

## 诊断和回归

诊断开关默认关闭，限制采样时长/数量，透明转发原调用，在 finally 中恢复 hook/临时对象/相机/配置。长日志分摘要与明细，避免控制台截断。每个性能变化记录包含/排除哪些子调用和取样环境。

| 门禁 | 必须通过的内容 |
|---|---|
| 源与作者化资产 | 无缺失脚本、引用落盘、重开可读、场景/Prefab一致 |
| 编译产物 | 目标工具链成功、实际模块/helper语义正确 |
| 加载与初始化 | 冷启动、后续包、ready时点、重试、缓存与释放 |
| 视觉与行为 | 同条件画面、真实按钮、滚动/切场景/保存，非自动深链替代 |
| 性能 | 同场景帧时间/热点/内存和DC，未转移为更大成本 |
| 发布 | 本地/远程摘要、域名/HTTPS、真机/弱网、回滚映射 |

当前资料中的历史日志未随包携带，案例自述的“构建通过”不能自动升级成“真机、整游、逐像素通过”。若环境缺失，列出具体门禁及影响范围。
