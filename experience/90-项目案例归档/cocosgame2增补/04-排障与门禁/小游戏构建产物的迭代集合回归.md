# 小游戏构建产物的迭代集合回归

重组日期：2026-09-27。

新增知识：源码 TypeScript 检查通过，并不保证目标平台构建后的 Map/Set 展开语义正确。Idlecat 的 Creator 小游戏产物曾把 `[...map]` 转成 `[].concat(map)`，后续解构得到 undefined。对明确的 Map/Set 使用 `Array.from(map.entries())`、`Array.from(set)`，并检查实际输出，不能只验证另一套编译器的结果。

回归应执行实际产物模块与随包的 Babel helper，覆盖多元素、重复元素、并发加载、失败重试和释放；GPU 模拟只验证状态与缓存逻辑，文字视觉仍须在目标模拟器复测。按静态类型审查 iterable 展开，避免无依据地重写所有数组展开。

资源清理要同时审查序列化 UUID、压缩 UUID、动态路径及工具依赖，备份原文件和 meta 并验证哈希。通过编辑器 AssetDB 删除资源；分别报告源工程节省量与实际构建包节省量。

案例：[Idlecat 字体分包与资源清理](../90-项目案例归档/2026-09-27-idlecat-字体分包与废弃资源清理-阶段复盘.md)。

## 2026-09-27 追加：按需 UI 的一致性门禁

先审计跨树序列化引用，再通过编辑器从当前实例同步 Prefab。逐字段比较渲染层/变换/字体/材质/动画，不能只比节点数量。多个 UI 根要在激活前完成关联，并保持原父节点与 sibling index。加载请求去重、加载失败重试、页面切换取消和场景销毁回调都应验证。拆包减少首屏依赖不等于减少总包或 Draw Call，必须分别测量。
