# Cocos 分组烘焙网格与去重校验

更新日期：2026-10-09。

参数生成能力与运行时生成不能混为一谈；先核实 baked 标记、已有 Mesh 引用和生命周期分支。按内容分包时可将一组多关网格合并为一个多 Mesh glTF，并在组内按顶点属性、索引及绘制模式精确去重，保持组间独立。颜色、UV、切线常含渲染语义，不能为去重直接删除。

导入后读取实际子资源 UUID，更新引用通过原生编辑器 API，先做逐属性精确对照和完整配置不变检查，再备份删除旧文件。大型源文件复制与导入可能竞争；检查 imported 和子资源数量，必要时待文件完整落盘后原生 reimport。

一个 glTF 源文件不意味着运行时加载全部子 Mesh；通过 UUID 按关卡读取。工程文件减少、ZIP 体积、运行时内存是不同指标，分别验证。Web 预览不能证明小游戏远程 ZIP 真机加载。
