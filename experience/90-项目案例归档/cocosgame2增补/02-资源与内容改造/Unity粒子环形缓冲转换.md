# Unity 粒子环形缓冲转换

重组日期：2026-10-09。新增知识：Main 模块不能只读取 lifetime/loop；ringBufferMode=1 会保留寿命末端的粒子，普通到期销毁会漏掉常亮光芒。应先审查发射方式与容量替换需求，不能靠无限延长寿命或反复重播替代。

单次同时出生、固定寿命、无后续发射可在原生粒子寿命末端暂停整个系统。持续发射或不同寿命不能使用这个简化；必须保留替换语义。Creator 版本升级需复测局部时钟兼容接口。
