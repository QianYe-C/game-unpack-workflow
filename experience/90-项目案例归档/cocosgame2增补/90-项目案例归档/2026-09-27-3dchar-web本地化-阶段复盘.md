# 3dchar Web 本地化阶段复盘

日期：2026-09-27

## 目标
将用户指定的 LAYERLAB 3D Characters Pro Fantasy Demo 保存为本地 Web 工程；遵循六目录工作流。

## 阻塞与根因
原站 CSS 的 TemplateData/webgl-logo.png 返回 404，属于远端失效引用。浏览器运行日志可读，但多种截图接口均返回 Unable to capture screenshot，无法完成视觉/交互验收。

## 动作
项目位于 myprojects/3dchar，原始入口与 11 个有效运行资源保存在 input/original；webprojects 保存运行工程，移除 itch.io htmlgame.js 与失效背景图引用。核心 Build 文件未修改，总下载有效资源 99,365,687 字节。增加仅监听 127.0.0.1 的 Python 静态服务器并提供 WASM MIME。导出 UnityWebData 6 条文件索引及内嵌 JSON/boot.config 到 sourceConfigs。

## 验证证据
本地地址 http://127.0.0.1:8333/；2026-09-27 23:54 启动。logs/http-server.log 的启动资源全部 HTTP 200；logs/browser-console.json 确认预设 0–9 成功加载；页面 loading 层为 none，无 warning banner。logs/integrity-check.json 核心文件哈希、WASM 魔数和 data 容器边界通过。当前 GPU 不支持 URP Edge Adaptive Spatial Upsampling shader，但初始化完成。

## 遗留风险与边界
视觉和按钮交互未验收；未声称完成所有预设组合测试。交付为 Unity WebGL 发布构建，不包含可编辑 Unity Editor 源码或商业 FBX 源资产。未额外导出模型贴图，未制作 TT 包。根目录旧 outputs/tmp_hex/替换修改 等为既存目录，本次不作无关清理。
