# Idlecat 设置静音偏好持久化阶段复盘

日期：2026-09-28

## 问题

设置页的 BGM、Sound、Vibration 三个开关只改了当前组件字段。刷新页面、切换 QA profile 或替换游戏存档后，状态回到导出初始值，和原版 SaveData 字段行为不一致。

## 实现

原版 `SaveData` 已确认包含 `BGM_Mute`、`SFX_Mute`、`Vibration_Mute`。现将三个字段加入 `WeaponLocalSave` 白名单，并在 `GameEconomy.settingsSnapshot/saveSettings` 中通过现有 `writeBuffSave` 原子写回。`NativeSettings` 优先读取和写入 GameEconomy；旧版本没有这三个字段时才读取版本化 `<weapon-profile>.settings.v1` localStorage 并在下一次切换迁移，缺失或损坏值安全回退为三个 false。

三个开关节点同时补回 `NativeButtonSfx` 和 `NativeBounceButton`，保持原始 SFX=1、WantSize=0.9、UpTime=0.1 的反馈；按钮事件与视觉尺寸不变。BGM 和音效仍复用已有 `NativeBgm`、`NativeSfx` 事件/门控。震动继续发出 `native-vibration-mute`，没有虚构抖音 SDK；真实平台适配属于 SDK 阶段。

## 验收条件

打开设置页，分别切换 BGM、Sound、Vibration；刷新同一 URL 后三个指示器保持对应状态，重新加载存档后仍从 `BGM_Mute/SFX_Mute/Vibration_Mute` 恢复。关闭设置页再打开时，BGM 音量和 Sound 门控即时对应当前状态。震动在浏览器仍为事件边界，待真实平台 SDK 接入后验证设备反馈。
