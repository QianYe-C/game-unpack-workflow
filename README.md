# 解包工具流

用于游戏解包、构建包本地化、资源导出回写、平台迁移与有范围的可编辑工程重建。适配范围由输入格式、引擎版本、脚本/资源完整性和原版证据决定。

- **新项目从 [新游戏迁移还原入口](新游戏迁移还原入口.md) 开始**：先选交付目标、输入类型与实际问题。
- [复杂还原方法](experience/05-复杂还原方法/README.md)：资产、UI、原生逻辑与物理、粒子与渲染、业务存档、构建性能。
- [工具目录](tools/工具目录.md)：实际随附脚本、依赖、调用和退出码。
- [工作流说明](工作流说明.md)：项目目录、输入/过程/输出和归档约定。
- [知识目录](experience/README.md)、[整合说明](整合说明.md)、[来源与历史边界](备份说明.md)。
